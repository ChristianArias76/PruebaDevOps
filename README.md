# PruebaDevOps

Proyecto base en HTML, CSS y JavaScript para pruebas de DevOps.

## Requisitos

- Node.js 18 o superior

## Uso

```bash
npm start
```

Abre http://localhost:3000 (el puerto se cambia con la variable `PORT`).

## Estructura

```
public/
  index.html
  css/styles.css
  js/app.js
server.js      servidor estático sin dependencias
package.json
```
